# Project Title
Distance Calculator Gonzales_8_Molave

## Description
My code asks you to input the X and Y values and turns them into coordinates. After inputting the X1, X2, Y1, Y2 it calculates the distance between the
two coordinates by using a mathematical formula

## How to Run
1. Open the program.
2. Run the code
3. Enter the X, and Y values.
4. Get the answer.

## Input Needed
The user needs to input the X and Y so the code can get the coordinates and solve the distance.
